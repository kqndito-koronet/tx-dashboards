Definitions

Segment & Metric Definitions

Core + eShop
Wholesalers with Komet Core system AND at least one active eShop (buyer-facing storefront). Can sell via eCommerce, API, and K2K channels.
Core + API (sells via API)
Wholesalers with Komet Core that sell online via API channel. Includes Mayesh (API-heavy), KBC, Pikes Peak. Note: $25.1M API GMV from 3 accounts pays $0 in API fees.
Core (online, no eShop, no API)
Wholesalers with Komet Core that sell online (via eCom or K2K) but do NOT have an eShop or API sales.
Core (offline only)
Wholesalers with Komet Core that had ZERO online sell-side activity in the period.
K2K + eShop
Wholesalers connected via K2K that also have an eShop. 100% of their sell GMV is online.
eSuite
Wholesalers using eSuite product. Fee type = "Gross Profit Share".
K2K only
Wholesalers connected via K2K WITHOUT an eShop. Can sell and buy through K2K but no buyer-facing storefront.
Procurement only
Wholesalers that ONLY buy through Koronet Procurement. $0 direct fees but create INDIRECT fees on the vendor side. Procurement data filtered to wholesaler industry only.
Other / Unknown
Wholesalers in Koronet with no clear classification or minimal/no activity in the period.
Vendors Connected
Vendors that have ever had a K2K connection with this segment. Equivalent to "Vendors Online" in Phase 2 data.
Vendors Active L30D
Vendors that transacted (bought from) in the last 30 days. Subset of Vendors Connected. Source: PROCUREMENT_DETAILS L30D filter.
Ninfa Flowers Distortion
Ninfa Flowers shows $514M in H1 2025 Buy-Side GMV -- data quality issue. Network-level Buy YoY is meaningless with Ninfa included. Excluding Ninfa: ~$142.5M and YoY = +21.0%.
Axerrio Gap
Axerrio fees (~$54K in H1 2026) are outside Snowflake and excluded from all fee totals per Data Rule 10.
