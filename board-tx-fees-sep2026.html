Channel definitions (channels.json, owner: Sofia Pardo):
Offline — Phone orders, manual ERP entry, standing orders, walk-in. Does not generate TX fees.
eCommerce — Buyer places order through vendor's eShop storefront. Generates fees (default 1.5%).
K2K — Komet-to-Komet inter-company transaction. Generates fees (double-charged: buyer + seller).
API — Order placed via public Komet Sales REST API. Generates fees (rate varies).
Procurement (buy-side) — Tracked in PROCUREMENTS_SV. Channels: API_K2K (code 9), ECOMMERCE_K2K (code 10), PROCUREMENT_LITE (code 11).
Online = eCommerce + API + K2K. Procurement (buy-side) tracked separately.
