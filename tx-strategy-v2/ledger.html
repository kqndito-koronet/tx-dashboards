Schema

Minimum fields for every ledger row

FieldRequiredMeaning
source_typeYescall, slack_feedback, github_issue, dashboard, agent_proposal, meeting, manual.
read_safe_summaryYesShare-safe summary; no private commentary.
initiativeYesBUY, LIST, SELL, GROW, Strategic, Enablers, OKR, System.
conversation_expectedYes for initiative rowsExact owner/customer conversation the row is trying to trigger.
expected_outcomeYes for Friday rowsOperational result expected this week.
expected_learningYesWhat we learn if the outcome does not happen.
kpi_or_leading_indicatorYesMetric used to judge the motion.
objection_or_blockerYes after touchCustomer/stakeholder objection, blocker, or no-response reason.
before_friday_owner_taskYesSmallest owner action needed before Friday review.
workflowYesRegistered workflow or Workflow missing.
owner_laneYesRose, Mercurio, Socrates, Pablito, Nahua, Codex, Lautaro, Facu, stakeholder.
value_prop_requiredYesYes/no; required for plays, talk tracks, objections, stakeholder notes.
trust_labelYesVerified, Directional, Inferred, Pending reconciliation, Needs owner validation, Not board-ready.
approval_stateYesDraft, Proposed, Needs Facu, Needs owner, Needs Lautaro, Approved, Rejected, Parked, Quarantined.
downstream_artifactYesHub, Friday pack, Monday prefill, account plan, value prop update, dashboard gap, workflow patch, CR.
