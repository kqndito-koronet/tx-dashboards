Routing rule

If no workflow matches, the output stays draft.

ConditionActionPromotion rule
Request matches a registered workflow.Run that workflow and log pre-reads, owner, output, feedback.Can update hub/ledger after review gate.
Request does not match a workflow.Run as ad hoc, log why, keep output draft.After 3 repeats, Nahua proposes workflow.
Output changes strategy, KPI, scope, owner, target accounts, or client-facing claims.Pause at Facu/Codex review packet.Cannot become operating guidance without approval.
